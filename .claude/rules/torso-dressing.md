# 착장 토르소 규칙

토르소(마네킹)에 상품을 입히는 작업은 `.claude/skills/torso-dressing/SKILL.md` 순서를 따른다.

1. **상품 이미지는 dcs-ai MCP 의 공식 제품컷만 쓴다** (`get_kr_products_color_images`, image_seq 23 정면 / 24 뒷면).
   쇼핑몰 페이지 크롤링, 임의 검색 이미지, 다른 상품 사진으로 대신하지 않는다.
2. **착장은 걸이 상품과 색·광택·디테일이 같아야 한다.** GPT 로 입힌 4면 → UniForge3D generate_3d →
   **반드시 paint_texture (photo_hanger=False) 로 다시 칠한다.** generate_3d 자체 텍스처는 쓰지 않는다.
3. 3D 로 넘기기 전에 입힌 4면을 직접 보고 상품컷과 다르면(색, 로고, 후드, 기장) 다시 만든다.
4. 결과는 `build_torso.py` 로 토르소 틀(받침 원판 기준)에 맞춰 `상품/착장/<품번 스타일명>/<품번>_<컬러>.glb` 에 넣는다.
   맨 토르소(`부품/토르소.glb`)·원본 사진(`부품/토르소_원본/`)은 지우거나 바꾸지 않는다.
5. 완료 보고 전에 웹(3939, 사용자가 띄운 서버)에서 M01 착장과 같은 상품의 걸이 버전을 나란히 보고 확인한다.
6. 입힌 4면 원본은 `data/torso/<품번>_<컬러>/` 에 남긴다 (다시 칠하거나 다시 만들 때 쓴다).
